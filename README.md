# Edgar Guzman

## Setup

Run the following command:

```sh
mkdir edgarguzman-monorepo; cd edgarguzman-monorepo
```

```sh
git clone git@github.com:edgar-guzman/edgarguzman-monorepo.git .
```

```sh
pnpm i
```
